# Maji Ndogo: Water Access Analysis

## Project overview

This end-to-end ALX project examined why residents in Maji Ndogo relied on river and rainwater despite boreholes being provided in the community. I completed the project in April 2026.

## My work

I analyzed the water-access problem using SQL, Python, Power BI and Excel. Community feedback helped explain why residents could not rely on the boreholes.

## Key findings

- The number of boreholes was too small for the size of the community.
- Residents reported that low-quality materials affected the boreholes.
- Access to the boreholes was not reliable or available at all times.
- Corruption among officials responsible for providing clean water was identified as a concern.
- These barriers contributed to residents relying on river and rainwater.
